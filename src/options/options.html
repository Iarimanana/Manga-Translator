Translation engine

Google Gemini

  1. Open Google AI Studio → API keys and sign in with a Google account.
  2. Click Create API key and copy it. No payment method is needed for the free tier.
  3. Paste it below and click Test connection.

Free-tier limits change often: roughly 10 pages a minute and a daily cap that depends on the model (from a few dozen to several hundred pages). Your current limits are shown in AI Studio → Usage. Each page is one request (very tall webtoon images use a few); cached pages are free.

Advanced

Local model

  1. Install Ollama (or LM Studio).
  2. Download a vision model in a terminal: ollama pull qwen2.5vl:7b (≈6 GB; needs ~8 GB of RAM/VRAM. Use qwen2.5vl:3b on smaller machines.)
  3. Let the extension talk to Ollama: set the environment variable OLLAMA_ORIGINS=chrome-extension://* and restart Ollama.
    How?

    Windows: Settings → System → About → Advanced system settings → Environment Variables → New user variable OLLAMA_ORIGINS = chrome-extension://*, then quit Ollama from the tray and start it again.

    macOS: run launchctl setenv OLLAMA_ORIGINS "chrome-extension://*", then quit and reopen Ollama.

    Linux (systemd): sudo systemctl edit ollama, add [Service] and Environment="OLLAMA_ORIGINS=chrome-extension://*", then sudo systemctl restart ollama.

    LM Studio: Developer tab → start the server (enable CORS) and load a vision model.

  4. Click Test connection below.

Tip: lower Image resolution sent to the model (below) to 1024–1280 to speed up slower computers. Pages are translated one at a time.

Claude API

Pages are read and translated by Claude using your own Anthropic API key. Create a key in the Anthropic Console. The key is stored only in this browser and is sent only to the Claude API.

Translation

Localisation workflow

Each page goes through the steps of a professional release: translation & adaptation → editing & proofreading → image cleaning → typesetting → SFX → quality control.

Typesetting picks lettering by delivery: heavy lettering for shouting, small light lettering for whispers, italics for thoughts, and balanced line breaks inside each balloon. Quality control checks for leftover Japanese, untranslated lines and text too long for its balloon, and sends problems back to the editor.
